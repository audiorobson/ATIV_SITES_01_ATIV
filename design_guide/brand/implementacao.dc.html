01 — Precedência

Quem manda, em ordem.

Sem essa hierarquia, em três meses existem dois valores de âmbar no código e ninguém sabe qual é o certo.

1

O CSS mestre vence

brand/tokens/ativ-ui.css é a fonte de verdade. Cor, tipo, espaço, raio, foco, grade, movimento e ícone saem de lá.

2

Tailwind é derivado

tailwind.ativ.js e theme.ativ.css nascem do CSS. Divergiu? Regenere o derivado — nunca o contrário.

3

Fora do CSS não existe

Cor nova, espaçamento novo ou duração nova entram primeiro no CSS mestre, com justificativa escrita, e só então no código.

04 — Tokens em código

Como consumir os valores.

Um componente nunca declara hex. Ele lê o papel, e a superfície resolve. Trocar .ativ-escuro por .ativ-claro troca o componente inteiro, inclusive o destaque e a cor do anel de foco.

Certo
// CSS puro
background: var(--ativ-superficie);
color: var(--ativ-texto-corpo);
padding: var(--ativ-e-5);
border-radius: var(--ativ-raio-cartao);
// Tailwind
class="bg-indigo-800 text-indigo-300
       p-e-5 rounded-cartao"
Errado
background: #262B4D;
color: #B6BAD0;
padding: 22px;
border-radius: 12px;
class="bg-[#262B4D] p-[22px]"
hex literal, valor fora da escala,
e o componente não segue a superfície.

05 — Iconografia

Lucide, e só Lucide.

Família oficial: lucide.dev, licença ISC, uso comercial livre. Grade 24×24, traço 2, extremidades arredondadas, sem preenchimento, cor herdada do texto.

Uso em React
// importação nomeada — nunca o pacote inteiro
import { Network, Radio, ShieldCheck }
  from 'lucide-react';
// decorativo
<Network className="ativ-icone" aria-hidden />
// única etiqueta do controle
<button aria-label="Fechar">
  <X className="ativ-icone" aria-hidden />
</button>
Classes de tamanho no CSS mestre: .ativ-icone--16 · 20 · 24 · 32 · 48. Acima de 24 o traço afina para manter o peso ótico.
Regras
→Cor sempre herdada do texto ao lado. Só --destaque desvia.
→Um ícone por elemento, à esquerda do rótulo, colado por 8 px.
→Se o ícone não carrega informação que o texto não carrega, remova.
✕Ícone preenchido, emoji ou outra família.
✕Abaixo de 16 px — nesse tamanho, use texto.
✕O símbolo power da marca como ícone. Ele é identidade, vive em brand/logo/ e nunca entra em grade de ícones. Para "energia" ou "operação", use a Lucide.

07 — Quando o sistema não cobre

Não improvise. Declare.

Duas famílias ainda não existem, e ambas dependem de material real da ATIV: vocabulário de dado técnico — tabela de especificação, bloco de spec, medidor, diagrama de sinal — e direção de fotografia. Preencher essas lacunas com tabela genérica, ícone de biblioteca ou imagem de banco é exatamente o que o README raiz proíbe, e é o que faz o resultado parecer template.

Faça

Marque a lacuna, liste a pendência e siga. Slot vazio declarado é melhor que preenchimento genérico.

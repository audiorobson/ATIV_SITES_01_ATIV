# Mídia editorial

Inventário das imagens versionadas usadas nas superfícies públicas.

**Regra:** arquivo em `apps/web/public/media/` não entra no site como evidência de obra. Diagrama, textura e ilustração técnica permanecem ilustração até existir fotografia real catalogada aqui.

## Status

- `illustrative` — diagrama ou ilustração técnica; não é fotografia de obra, case ou cliente;
- `candidate` — ativo real ainda sem aprovação comercial;
- `approved` — ativo real aprovado para a rota.

## Contratos

- alt descreve o que a imagem mostra, sem atribuir cliente, contrato ou resultado;
- legenda declara o tipo do ativo quando ele não for fotografia;
- origem, ferramenta e créditos ficam no inventário da pasta, não no HTML.
